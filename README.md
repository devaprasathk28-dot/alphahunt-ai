# 🚀 ALPHAHUNT AI

### GenAI-Powered Global Stock Intelligence Platform  
**From Data to Decisions — Real-Time, Global, Intelligent**

---

## 🌍 Overview

ALPHAHUNT AI is a real-time, GenAI-powered system that analyzes global stock markets and converts raw financial data into **actionable investment decisions**.

Unlike traditional dashboards, ALPHAHUNT AI:
- Detects opportunities early
- Explains *why* a stock matters
- Provides intelligent recommendations

---

## 🧠 Key Features

- 🌍 **Global Stock Coverage** — Supports any stock (AAPL, TSLA, RELIANCE.NS, etc.)
- ⚡ **Live Market Data** — Real-time updates using yFinance
- 📈 **Interactive Charts** — Live updating graphs using Plotly
- 🧠 **AI Reasoning Engine** — Explains signals with GenAI
- 📰 **News + Sentiment Analysis** — Understands market mood
- 📊 **Signal Detection System** — RSI + Trend + Momentum logic
- 🏆 **Opportunity Ranking** — Identifies best stocks to watch
